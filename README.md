**专为自媒体创作者设计的每日高效工作流技能**

## 📋 技能简介

这个技能帮助你建立可持续的内容创作系统，覆盖**选题 → 创作 → 优化 → 发布 → 分析**全链路。

适用于：抖音、 小红书、微信公众号、B站、X/Twitter 等平台。

## 🚀 触发方式

- “自媒体每日工作”
- “帮我规划今天的内容创作”
- “content creator daily routine”
- “自媒体创作者日程”

## 📅 标准每日工作流程

### 1. **晨间规划 (30-45 分钟)**
- 热点追踪（热搜、平台算法、竞品）
- 选题 Brainstorm（IP定位 + 受众痛点 + 时事）
- 当日内容计划（1-3 条核心内容）

### 2. **内容创作 (2-4 小时)**
- 文案/脚本撰写
- 素材采集与制作（CapCut / Canva）
- SEO 优化（标题、关键词、标签、封面）

### 3. **优化与定时发布 (30 分钟)**
- 平台规则检查
- A/B 测试标题准备
- 多平台分发计划

### 4. **互动与社群维护 (45-60 分钟)**
- 回复评论
- 粉丝互动
- 跨平台引流

### 5. **晚间复盘 (20-30 分钟)**
- 数据分析（播放量、完播率、点赞、评论）
- 当日总结 + 明日优化

## 🛠️ 推荐工具栈

- **规划**：Notion / 飞书
- **创作**：CapCut、剪映、Canva、ChatGPT/Grok
- **发布**：各平台后台 + Buffer / Hootsuite
- **分析**：平台数据后台 + 飞瓜数据 / 西瓜数据

## 📈 Best Practices
- 使用番茄钟 + Eisenhower 矩阵管理时间
- 批量创作（每周固定 1 天拍 7 条视频）
- 内容矩阵运营（长视频 → 短视频 → 图文）
- 防止 burnout：每天固定输入时间（读书、刷优秀账号）
